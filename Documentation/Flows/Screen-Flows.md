# Screen Flows

A screen flow is a flow type that requires user interaction as it includes screens, local actions, steps, choices, or dynamic choices. 
Invoke a screen flow from many distribution methods, such as Lightning pages, Experience Builder pages, Lightning web components, Aura components, custom buttons, actions or links, and Flow Orchestration
Screen flows provide a way to guide users through a business process; they provide instructions or call scripts, prompt users to complete certain fields, and then perform actions behind the scenes such as Record Create or Record Update.
Use a screen flow to collect data or display data to users. 

# Screen Flow Element

Add Screen ELement to your flow to create interactive user interfaces without any code.

1. Components Panel - panel on the left represents the items available to be displayed within the screen element. Standard, custom and appExchange based packages can all be found here. Custom components are built as Lightning Web Components and require LWC development knowledge, but there are some custom components available for access through the AppExchange and third-party open sources
2. Attributes - Properties defined for the elements/components Panel items
3. Canvas - Middle section represents the canvas where you can drag and drop elements
4. Fields - On the Components Panel, you can also configure record variable to bind the fields directly from the object.
