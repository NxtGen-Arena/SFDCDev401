# Apex Test Class




## Annotations

|Annotation|Scope|Description
|-----------|-----|----------|
|@isTest|Class, Method|Indicates the class or method is part of test class. Does not count against the Orgs Apex Limits
|@isTest(SeeAllData=True)|Class,Method|By default Org's data is not accessible in the test classes. This annotation allows to query the org's data in test classes. There are certain objects which cannot be instntiated in the classes e.g: history records. So, the only way to access them is to query actual data.
|@testSetup|Method|used to indicate a method is specifically used to set up test data. When supplied, the @testSetup method is executed before any other methods in the test class. Each test method will have access to the original set of constructed test data regardless of how any other test method uses that data.
|@testVisible|Class, Method, Variable| Enables test class and methods to access Private and Protected class, method and variables. Otherwise code coverage may not reach it's level. Use it carefully and only in situations where the internal calls are not functionally covering the private or protected code.

## Test Class Methods

|Method|Parameters|Description|Example
|-----------|----------|----------|
|System.Assert|Expression to evaluate| returns true or false based on the expression|system.assert(accnt.NoOfActiveContacts__c > 0)
|System.AssertEquals|Expected,Actual|Compares Expected vs Actual and returns true or false|System.AssertEquals(300, accnt.No_Of_Active_Contacts__c)
|System.AssertNotEquals|Expected,Actual|Compares Expected vs Actual and returns true or false|System.AssertNotEquals(0, accnt.No_Of_Active_Contacts__c)
|System.runAs()|User|All Apex code runs in system mode, where the permissions and record sharing of the current user are not taken into account. The system method runAs enables us to write test methods that change the user context to an existing user or a new user so that the user’s record sharing is enforced. The runAs method doesn’t enforce user permissions or field-level permissions, only record sharing. 
|Test.loadData()|csv path from static resource|populate data in test methods without writing any code lines, using csv file
