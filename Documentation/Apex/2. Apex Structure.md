# Structure of Apex Language

- Apex uses classes to define code to be executed. 
- Salesforce also provides out of the box classes which you can use in the Apex.
- Apex is strongly typed so we need to define the data type and return types.
- Code blocks starts and ends with  { }
- Statements must end with ;
- Names are case-insensitive.

Like any other language Apex also consists of programming elements like

1. [Variables](Apex_Data_Types_&_Variables.md) - Variables are declared with a name and a data type
2. Statements (assignments, declarations) & Methods to process, exceute business logic
3. [Control Structures (branching)](Apex/) - If (If, If-Else, Nested If-Else), Do-While, While, For etc
4. [Collections](Collections_in_Apex.md) - Lists, Maps, Sets
5. [DML](Data_Persistence_using_DML.md) and [SOQL](Retrieve_Data_using_SOQL.md) for data
7. Exception handling using Try-Catch & Custom
