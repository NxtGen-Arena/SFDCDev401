## What is an Object on the force.com platform

An object on the force.com platform is similar to a database table. 

* Object - Real-life entity like Employee, Company. 
* Fields - Columns storing individual data value with defined data type.
* Record - Rows of data for single entity representation where values are populated in each individual column.
* Data Value - Value in single field or record.
