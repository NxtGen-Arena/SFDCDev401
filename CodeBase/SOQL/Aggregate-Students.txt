⚠️ Assumption (important):
These are custom objects

College__c (parent)

Student__c (child)

Lookup field: Student__c.College__c

Child relationship name assumed as Students__r
(If your org uses a different child relationship name, replace it accordingly.)

✅ SOQL ANSWERS (College–Student Use Case)
1️⃣ Count of Students per College
SELECT College__c, COUNT(Id)
FROM Student__c
GROUP BY College__c

2️⃣ Average Age of Students per College
SELECT College__c, AVG(Age__c)
FROM Student__c
GROUP BY College__c

3️⃣ Colleges with More Than 10 Students
SELECT College__c, COUNT(Id)
FROM Student__c
GROUP BY College__c
HAVING COUNT(Id) > 10

4️⃣ Oldest Student in Each College

⚠️ SOQL limitation: Use aggregate (no student name)

SELECT College__c, MAX(Age__c)
FROM Student__c
GROUP BY College__c


👉 To fetch the actual student record, Apex is required.

5️⃣ Number of Students Enrolled After 2020, Grouped by College
SELECT College__c, COUNT(Id)
FROM Student__c
WHERE Enrollment_Date__c > 2020-12-31
GROUP BY College__c

6️⃣ Number of Students per College (Sorted Descending)
SELECT College__c, COUNT(Id)
FROM Student__c
GROUP BY College__c
ORDER BY COUNT(Id) DESC

7️⃣ Colleges with No Students Enrolled
SELECT Name
FROM College__c
WHERE Id NOT IN (SELECT College__c FROM Student__c)

8️⃣ Students Whose College Was Established Before 2000
SELECT Name, College__r.Name
FROM Student__c
WHERE College__r.Established_Year__c < 2000

9️⃣ Total Students Enrolled in the Last Year per College
SELECT College__c, COUNT(Id)
FROM Student__c
WHERE Enrollment_Date__c = LAST_N_YEARS:1
GROUP BY College__c

🔟 Colleges with Average Student Age Below 22
SELECT College__c, AVG(Age__c)
FROM Student__c
GROUP BY College__c
HAVING AVG(Age__c) < 22

1️⃣1️⃣ Count of Students Grouped by College Location
SELECT College__r.Location__c, COUNT(Id)
FROM Student__c
GROUP BY College__r.Location__c

1️⃣2️⃣ Students from Colleges Located in 'Delhi'
SELECT Name, College__r.Name
FROM Student__c
WHERE College__r.Location__c = 'Delhi'

1️⃣3️⃣ List All Students Along with Their College Name
SELECT Name, Email__c, College__r.Name
