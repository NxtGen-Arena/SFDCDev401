📌 ASSUMPTIONS (Very Important)

Parent Object: College__c

Child Object: Student__c

Lookup Field: Student__c.College__c

Child Relationship Name: Students__r

🔁 If your org has a different child relationship name, replace Students__r.

🔁 SOQL USING PARENT SUBQUERIES
1️⃣ Count of Students per College
SELECT Name,
       (SELECT COUNT() FROM Students__r)
FROM College__c

2️⃣ Average Age of Students per College

⚠️ NOT supported directly in parent subquery

✔️ Salesforce does not allow AVG() inside subqueries

👉 Must be done using child aggregate query (already shown earlier) or Apex.

3️⃣ Colleges with More Than 10 Students
SELECT Name
FROM College__c
WHERE Id IN (
    SELECT College__c
    FROM Student__c
    GROUP BY College__c
    HAVING COUNT(Id) > 10
)

4️⃣ Oldest Student in Each College
SELECT Name,
       (SELECT Name, Age__c
        FROM Students__r
        ORDER BY Age__c DESC
        LIMIT 1)
FROM College__c

5️⃣ Students Enrolled After 2020, Grouped by College
SELECT Name,
       (SELECT Id
        FROM Students__r
        WHERE Enrollment_Date__c > 2020-12-31)
FROM College__c

6️⃣ Number of Students per College (Sorted Desc)

⚠️ Sorting parents by child count not supported directly

✔️ Use child aggregate query instead
OR handle sorting in Apex.

7️⃣ Colleges with No Students Enrolled
SELECT Name
FROM College__c
WHERE Id NOT IN (SELECT College__c FROM Student__c)

8️⃣ Students Whose College Was Established Before 2000

⚠️ Parent subquery not applicable

✔️ Correct approach is child → parent

SELECT Name, College__r.Name
FROM Student__c
WHERE College__r.Established_Year__c < 2000

9️⃣ Students Enrolled in the Last Year per College
SELECT Name,
       (SELECT Id
        FROM Students__r
        WHERE Enrollment_Date__c = LAST_N_YEARS:1)
FROM College__c

🔟 Colleges with Average Student Age Below 22

⚠️ NOT possible in parent subquery

✔️ Requires:

SELECT College__c, AVG(Age__c)
FROM Student__c
GROUP BY College__c
HAVING AVG(Age__c) < 22

1️⃣1️⃣ Count of Students Grouped by College Location

⚠️ Parent subquery cannot group by parent fields

✔️ Child aggregate query required:

SELECT College__r.Location__c, COUNT(Id)
FROM Student__c
GROUP BY College__r.Location__c

1️⃣2️⃣ Students from Colleges Located in 'Delhi'

⚠️ Parent subquery not suitable

✔️ Correct solution:

SELECT Name, College__r.Name
FROM Student__c
WHERE College__r.Location__c = 'Delhi'

1️⃣3️⃣ List All Students Along with Their College Name
SELECT Name,
       (SELECT Name, Email__c FROM Students__r)
FROM College__c
