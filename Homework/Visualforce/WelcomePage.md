# Create a Basic Visualforce Page with Static Content and Global Variables

📋 Objective:
To build a simple Visualforce page that displays static content along with dynamic values using global variables like $User, $Organization, and $Profile.

📘 Instructions:

1. Create a Visualforce page named "WelcomePage".
2. Use HTML tags inside the page to structure the content (headings, paragraphs, etc.).
3. Display the following global variables on the page:
   * Logged-in User's Name → $User.FirstName and $User.LastName
   * Organization Name → $Organization.Name
   * User's Profile Name → $Profile.Name
4. Use some inline CSS to style the page (optional for extra credit).
5. Save and preview the page in Salesforce.
