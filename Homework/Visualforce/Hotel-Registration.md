# Hotel Registration Use Case

<h2> Introduction</h2>

## Scenario: Hotel Registration System

Imagine you are building a Hotel Registration System for a hotel chain. This system will allow:
- Guests to register and book rooms.
- Hotel staff to view guest details.
- Search functionality for reservations.
- Lightning integration for seamless experience.

<h3> Exercise 1: Creating a Basic Hotel Registration Page</h3>

**Objective**: Create a Visualforce page that allows guests to enter their details and book a room.

✅ Expected Outcome: Guests can enter their details and select a room for registration.

<h3> Exercise 2: Implementing Pagination for Guest List</h3>

**Objective**: Use a Custom Controller Extension to add pagination to the Guest List page.

✅ Expected Outcome: Pagination controls allow staff to navigate through guest records.

<h3>Exercise 3: Search Using JavaScript Remoting</h3>

**Objective**: Use JavaScript Remoting for faster, real-time search of guest reservations.

✅ Expected Outcome: As you type, the list updates in real-time with matching guest reservations.
