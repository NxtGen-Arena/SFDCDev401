# Hotel Registration Use Case

<h2> Introduction</h2>

## Scenario: Hotel Registration System

Building a reseration system that will allow:
- Guests to register and book rooms.
- Hotel staff to view guest details.
- Search functionality for reservations.
- Lightning integration for seamless experience.
- Make necessary assumptions and document.

<h3> Exercise 1: Creating a Basic Hotel Registration Page</h3>

**Objective**: Create a Visualforce page that allows guests to enter their details and book a room.

✅ Expected Outcome: Guests can enter their details and select a room for registration.

<h3> Exercise 2: Displaying a List of Booked Guests</h3>

**Objective**: Create a Visualforce page to display a list of registered guests.

✅ Expected Outcome: Display upcoming GUests reservtions with pagination

<h3>Exercise 3: Search Reservations</h3>

**Objective**: Allow hotel staff to search for guest reservations by name and modify the reservation. Search based on the Guest email, phone and/or dates of reservation.

✅ Expected Outcome: As you type, the list updates in real-time with matching guest reservations. Allow Staff to select the Reservation and make the adjustments.

<h3>Embedding Visualforce in Lightning</h3>

**Objective**: Display a guest’s reservation details in a Lightning Record Page for Reservation. 

✅ Expected Outcome: The Visualforce page appears inside Lightning for each guest.
